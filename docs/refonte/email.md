**Objet :** Conception de la future architecture de notre application

Bonjour,

Merci pour l’audit que vous avez réalisé sur notre CRM actuel. Nous souhaitons maintenant franchir une nouvelle étape : concevoir la future architecture de l’application.
Vous avez toutes les informations spécifiques à la future application dans la fiche descriptive de la mission ci-jointe.

À partir de vos constats, nous vous demandons d’un document d’architecture (format PDF) qui présente :

- le contexte et les objectifs de la refonte (performances, disponibilité, maintenabilité, évolutivité) ; 
- une vue d’ensemble de l’architecture applicative cible (front, back, base de données, interactions entre les différents composants) ;
- une vue d’ensemble de l’architecture opérationnelle (docker, télémétrie, etc.)
- un modèle de données adapté aux besoins du CRM ; 
- la justification architecturale (organisation du code, communication front/back, grandes décisions de conception).

En complément, nous attendons que vous prépariez les scripts SQL nécessaires à la nouvelle structure de données (par exemple les scripts de création du schéma PostgreSQL).

Pour ce travail, vous pourrez vous appuyer sur :

- votre rapport d’audit, 
- la fiche descriptive de l’application à refaire, 
- le modèle du document d’architecture à rédiger. 

Ce document nous servira de référence pour la suite du projet, lorsque nous passerons à l’implémentation.
