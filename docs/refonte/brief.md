Dans cet exercice, vous allez vous appuyer sur l’audit de l’application existante réalisé dans l’exercice 1 pour concevoir la refonte technique du CRM de LiVrai.

L’objectif est de définir une architecture cible full-stack moderne basée sur :
- un back-end en Java avec Spring Boot ;
- un front-end en Angular (avec la possibilité d’utiliser NgRx, encouragée mais non obligatoire) ;
- une base de données relationnelle PostgreSQL ; 
- une application prête à être conteneurisée avec Docker (au moins au niveau de la conception).

Vous n’allez pas développer la nouvelle application dans ce projet. Votre rôle est de jouer l’architecte : clarifier les objectifs de la refonte, concevoir l’architecture cible et poser les bases de la nouvelle structure de données.
